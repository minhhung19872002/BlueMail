# Dev-only DKIM keys

These RSA-2048 keys sign mail for the **non-routable test domains** `bluemail.test`, `acme.test`
and `doitac.test` inside the dev Docker network (10.77.0.0/24). They are published in
`deploy/coredns/zones/*.db` (generated by `scripts/dev-gen-zones.py`).

Never use them for a real domain. Production DKIM keys are generated per domain by BlueMail,
stored encrypted in `tenant.dkim_keys`, and never committed.
